# openStudio — Editorial Intelligence Studio

تطبيق macOS أصلي بالعربية والإنجليزية، مبني بـ SwiftUI، مع Python وAgno وSQLite مضمّنة في حزمة التطبيق.

**التسليم الحالي: 0.1.0 — إثبات التشغيل المستقل والمسار التحريري الأول. هذه ليست نسخة MVP مكتملة، ولا إصدارًا موثقًا لدى Apple.** الوثيقة الأصلية كاملة في [PRD.md](PRD.md)، والتغطية الفعلية والحدود في [docs/acceptance.md](docs/acceptance.md).

## جرّب التطبيق

افتح `dist/Editorial Intelligence Studio-development.dmg` من Finder ثم التطبيق الموجود داخله. يمكن نسخه إلى Applications. لا يحتاج المستخدم إلى تثبيت Python أو Docker أو تشغيل Terminal. بُنيت هذه الحزمة واختُبرت على Apple Silicon وmacOS 27؛ دعم macOS 14 كحد أدنى معلن في البناء لكنه لم يُختبر على جهاز مستقل بعد. Intel غير مبني. ملف DMG محلي تجريبي وغير موثق لدى Apple.

1. افتح **المحادثة** وناقش فكرة أو اختر نقاشًا سابقًا. تظهر المحادثة والمسودة واللوحة الجانبية معًا في النافذة الواسعة؛ في العرض الضيق بدّل بين **المحادثة / المسودة** دون فقد الكتابة.
2. من **الأخبار ← مكتبة المصادر** اختر مصدرًا مصنّفًا وأضفه بضغطة، أو أضف رابط RSS أو Atom، أو موقعًا يعلن خلاصة، أو مجتمع Reddit. يبدأ الجلب في الخلفية وتظهر الأخبار مع حالتها. افتح الخبر لقراءة النص المستخرج أو الملخص إذا تعذر المقال الكامل، وحدد الأخبار التي تريد مناقشتها.
3. من **كتاباتي** أضف أمثلة من كتابتك مع تحديد ملكيتها أو ترخيصها. يمكن تصنيف النص مرجعًا للمحتوى بدل عينة أسلوب. الأخبار منفصلة، ولا تُستخدم تلقائيًا لتغيير صوتك.
4. حلّل عينة الكتابة وراجع اقتراحها ومقتطفها، ثم اختر **أضف إلى أسلوبي** عند ملاءمتها. تكييف الأسلوب يستخدم أمثلتك وقواعدك في سياق الطلب، وليس تدريبًا للنموذج.
5. من **Settings… / ⌘, ← عام** اختر العربية أو الإنجليزية والمظهر. اضبط اتصالات النماذج في **الاتصالات** واختيار الكاتب والمحلّل في **الوكلاء**. في المحادثة اختر النقاش أو منشورات X المستقلة أو سكربت YouTube طويل أو سكربت TikTok، وحدّد الأخبار والمسودة المرفقة ووافق على استخدام النموذج. تحفظ المقترحات كمسودات منفصلة تفتحها للمراجعة، ولا تستبدل نصك الجاري تلقائيًا.
6. للكتابة اليدوية انتقل إلى **المسودة** واكتب واحفظ بـ **⌘S** دون حاجة إلى نموذج. افتح المحفوظ بـ **⌘O** وراجع الأدلة والنسخ، ثم صدّر Markdown بـ **⌘⇧E**. يبقى التصدير مسودة غير معتمدة.

الموافقة في المحادثة تغطي النقاش الجاري مع إعداداته وسياقه الظاهر؛ لا يلزم تفعيلها مجددًا لكل رسالة إذا بقي النطاق نفسه. تُصفّر عند فتح أو بدء محادثة أخرى، أو تغيير النموذج والصيغة والمدة أو خيارات السياق والمراجع والقواعد المعتمدة. تحليل مصدر بالنموذج واختبار الاتصال لهما موافقتهما المنفصلة.

**مساحة تحرير واحدة:** نقاش وكتابة وأخبار وكتابات شخصية، مع مظهر فاتح/داكن/تلقائي وحماية للتعديلات غير المحفوظة. اقرأ [المحادثة والأخبار والأسلوب](docs/chat-news.md) و[سجل إعادة التصميم](docs/ui-redesign.md).

مسارات التوليد متصلة بـ Agno وليست نصوصًا تجريبية. اختُبرت بعقود واستجابات اصطناعية معزولة؛ **لم ينفذ طلب مدفوع أو اختبار حي باستخدام مفتاح المستخدم**. الأسماء الافتراضية مصدرها نسخة Agno المثبتة، وليست ضمانًا لتوفر النموذج على حسابك.

تدعم الإعدادات اتصالات متعددة واختيار نموذج مستقل للكاتب والمحلّل. تُجلب قوائم النماذج من مصادر المزودين، وتُحدّث كل ساعة أثناء تشغيل التطبيق، مع زر تحديث فوري وبحث داخل القائمة. يتطلب الوصول إلى النماذج الخاصة بيانات حساب المزود.

## حالة اتصال المزوّدين

تعرض الإعدادات شعار المزوّد، طريقة الربط، حالة الاتصال، وآخر تحقق ناجح. حفظ مفتاح أو اختيار نموذج لا يعني أن الحساب اختُبر. يؤكد اختبار النموذج القدرة على الرد، وتُراجع جلسة ChatGPT عبر قائمة الحساب كل خمس دقائق أثناء تشغيل التطبيق دون طلب توليد مدفوع. يوجد زر تحقق فوري، وتُميّز أخطاء الشبكة والخدمة وحدود الاستخدام عن بيانات الدخول المفقودة أو المرفوضة. الحالات القديمة تظهر بحاجة إلى إعادة تحقق.

يفصل زر **فصل الاتصال** هذا الحساب على الجهاز ويزيل رموز الدخول أو المفتاح المحلي ويمنع طلبات الوكلاء عليه. يبقى اسم الاتصال واختيار الوكلاء محفوظين لتسهيل إعادة الربط. لا يلغي ذلك التفويض على موقع المزوّد أو جلساته في التطبيقات الأخرى. تعرض صفحة نجاح تسجيل الدخول تأكيدًا بالعربية أو الإنجليزية.

## قارئ شريط القوائم

أيقونة الصحيفة في شريط macOS تفتح قارئًا مصغرًا للأخبار: بحث، اختيار المصدر، غير المقروء، نص الخبر أو وصف الحلقة، ورابط المصدر الأصلي. زر «فتح مساحة التحرير» يعيد النافذة والمسودة نفسها. إغلاق النافذة الحمراء أو ⌘W يخفيها ويحفظ حالة الكتابة في الذاكرة؛ احفظ المسودة بـ⌘S لحفظها على القرص. «إنهاء التطبيق» من قائمة القارئ أو ⌘Q يوقف المحرك ويحذر من تعديلات غير محفوظة. لا يضاف تشغيل عند تسجيل الدخول، ولا تُوقظ هذه الميزة الجهاز من السكون.

## الموجود الآن

- حزمة `.app` مستقلة محليًا، Python قابل للنقل، توقيع ad-hoc لكل Mach-O من الداخل إلى الخارج.
- socket محلي خاص بصلاحيات 0600، وبروتوكول EIS-IPC/1 مع حد 1 MiB ورسائل تحقق وأخطاء منقحة.
- SQLite/WAL ومخطط v5 ومقاطع ذات مواضع وFTS5، وتحميل sqlite-vec مثبت فعليًا.
- منع تكرار الاستيراد والتحليل، حفظ نسخ التغيير، وربط كل تقنية بمقتطف حرفي.
- قواعد DNA باعتماد صريح، نسخ غير قابلة لتغيير نتائج المهام القديمة، وسحب اعتماد.
- دليل مستخرج من مفاتيح Agno الرسمية في الإصدار المقفل: 68 مدخلًا مع حالة جاهزية منفصلة.
- مهام مستمرة في SQLite، إلغاء واستئناف، سجل أحداث قابل للاستعادة بالرقم التسلسلي.
- محادثات محفوظة مع إلغاء الرد واستئنافه ضمن سياقه، ومقترحات محتوى محفوظة كمسودات مستقلة.
- اشتراكات RSS/Atom واكتشاف خلاصة الموقع وروابط Reddit العامة، مع تحديثات شرطية ومنع التكرار واستخراج المقالات المرتبطة.
- فصل أمثلة الأسلوب عن الأخبار والمراجع، واستخدام سياقي للكتابات المصرح بها دون تدريب أو fine-tuning.
- صيغ تحريرية متعددة ونسخ وتعديلات محفوظة؛ الروابط والأدلة المقترحة لا تتحول إلى حقائق معتمدة تلقائيًا.

## البناء والاختبارات للمطور

المتطلبات: Apple Silicon، أدوات Swift 6، SDK macOS، و`uv`. نسخة البناء التي تم التحقق منها: Swift 6.4، SDK macOS 27، CPython 3.12.13.

```bash
bash scripts/test.sh
bash scripts/build_app.sh
```

يستخدم البناء `engine/uv.lock` وملف متطلبات بـ SHA-256. تثبيت الحزم يحدث عند البناء فقط، ولا يحدث على جهاز المستخدم النهائي. يحتفظ runtime برخص توزيعات Python في `dist-info`، وقائمة اعتمادات في `Contents/Resources/dependency-inventory.json`. هذه القائمة ليست SBOM معتمدًا بمعيار SPDX/CycloneDX؛ هذا متطلب إصدار متبقٍ.

الشفرة الأصلية مشروع Swift Package يفتح في Xcode عبر `macos/Package.swift`. لا يوجد `.xcodeproj` مولّد أو اختبارات XCUITest في هذه المرحلة. اختبار المسار الأصلي تم كذلك عبر واجهة التطبيق الفعلية؛ التفاصيل في سجل القبول.

## البيانات والتكلفة

المسار الافتراضي:

`~/Library/Application Support/com.editorialintelligence.studio/default/editorial.sqlite`

احتفظ بنسخة أخرى من مكتبتك: توجد ترقية مخطط إلى v6 مع نسخة محلية قبل ترقية قواعد البيانات السابقة، لكن واجهة النسخ الاحتياطي والاستعادة الشاملة لم تُنفذ بعد. للنسخ اليدوي أغلق التطبيق ثم انسخ مجلد `default` كاملًا. مجلد `default/.providers` يحتوي ملفات بيانات الاعتماد؛ نسخه يتضمن مفاتيحك، فاحفظ النسخة في مكان خاص. انظر [الخصوصية](docs/privacy.md).

إضافة اشتراك أخبار تفعّل متابعته التلقائية، افتراضيًا كل ساعة أثناء فتح التطبيق، مع فحص المستحق عند إعادة التشغيل. إغلاق نافذة التحرير يخفيها فقط وتستمر المتابعة من شريط القوائم. اختيار «إنهاء التطبيق» أو ⌘Q يوقفها. إدخال رابط ضمن بيانات نص مستورد لا يحوله إلى اشتراك. لا تستخدم طلبات الأخبار جلسات المتصفح أو بيانات الدخول ولا تتجاوز حظر الوصول؛ يبقى الملخص عندما يتعذر المقال الكامل.

تعرض لوحة الأخبار أحدث 100 مادة محفوظة. يستخدم سياق المحادثة حتى 12 خبرًا محددًا، أو أخبارًا ذات تاريخ نشر معروف ضمن آخر سبعة أيام. تاريخ الاكتشاف لا يثبت حداثة الخبر، وهذه الحدود لا تعني تغطية شاملة لكل المصادر. إرسال المحادثة ومراجعها وكتابات الأسلوب إلى النموذج مرتبط بموافقة النقاش الظاهرة، وقد يترتب عليه تكلفة.

مخرجات YouTube وTikTok سكربتات نصية بمدة تقديرية، وليست فيديوهات منتجة. لا يوجد نشر للشبكات أو تشغيل سكربتات Skills أو تحقق صحفي مستقل من الوقائع. حدود الطلبات والنصوص والمهل موجودة؛ ميزانية نقدية دقيقة تعتمد على أسعار المزود والنموذج ولم تُنفذ بعد.

## القراءة واللغة ومكتبة RSS

يعرض التطبيق عناوين المقالات والقوائم والتغليظ والروابط القابلة للنقر. في المسودة توجد أدوات تنسيق للنص المحدد مع معاينة واضحة قبل الحفظ أو تصدير Markdown. اختر لغة الواجهة من **الإعدادات ← عام**؛ تتغير العربية/الإنجليزية واتجاه الواجهة دون تغيير لغة محتواك.

من **الأخبار ← مكتبة المصادر** ابحث أو اختر تصنيفًا وأضف الخلاصة بضغطة. زر **تعديل ملف المصادر** يفتح `sources.yml` الخاص بك، ثم **إعادة تحميل** لتطبيق التعديلات وإظهار التصنيفات الجديدة. [طريقة تعديل الملف وأمثلة YAML](docs/source-library.md).


## First-run setup and permissions

On first launch, OpenStudio guides you through language, provider/model, and an optional persistent AI-use permission. Existing connections are reused; a manual model test is not required. You can skip the provider to read and write locally. Change or revoke the permission, or reopen the guide, in **Settings → Permissions and setup**. After opting in, user-requested chat, generation and analysis do not repeat a consent checkbox. Closing the app window keeps the news reader running; quitting stops the engine.

The main sidebar offers **New conversation** (⌘N), history, saved drafts, Activity, and Settings. **⌘⇧N** creates a draft. See [setup and conversation verification](docs/conversation-setup-verification.md).


## Assistant customization and streaming

Open **Customize assistant** from Settings for shared preferences, from an agent for its specialization, or from a conversation header for that chat only. The six optional sections cover role, working instructions, writing style, background knowledge, examples, and response format. Advanced System/Developer fields are mapped to each provider's instruction channel; they are not advertised as separate native message roles on every provider. Your normal chat input remains the user request.

Preferences are saved locally and frozen when a job is submitted, including retries. Conversation responses stream from the provider with an actual progress state. Only completed, validated responses and drafts are saved. Existing UUID citations render as clickable numbered references. Read [customization and streaming verification](docs/assistant-customization-verification.md) for scope and tests.
