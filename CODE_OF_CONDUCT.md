# قواعد المجتمع / Community conduct

## العربية

نرحّب بالمشاركة بالعربية والإنجليزية. ناقش الأفكار والشفرة باحترام، وراعِ اختلاف الخبرة واللغة. لا يُقبل التحرش أو التمييز أو التهديد أو نشر المعلومات الخاصة أو الإغراق المتعمد للنقاش.

يمكن الإبلاغ عن سلوك مخالف عبر أدوات الإبلاغ في GitHub أو بلاغ للمشرفين دون معلومات شخصية. استخدم قناة الأمان الخاصة فقط للمشكلات الأمنية. قد يعدّل المشرفون المحتوى المخالف أو يحذفونه أو يقيدون المشاركة بناءً على السياق؛ يمكن طلب إعادة النظر في القرار داخل GitHub دون إعادة نشر محتوى مؤذٍ.

## English

Arabic and English participation is welcome. Discuss ideas and code respectfully and accommodate different experience levels and languages. Harassment, discrimination, threats, disclosure of private information and deliberate disruption are unacceptable.

Report conduct concerns with GitHub's reporting tools or a maintainer issue without exposing personal information. Reserve the private security channel for security issues. Maintainers may edit/remove content or restrict participation according to context. You may request reconsideration through GitHub without reposting harmful content.
