## Product truth

Discovery uses the public skills.sh search endpoint used by vercel-labs/skills. GitHub API reads public SKILL.md files at a resolved commit, following only same-service HTTPS redirects. Collections let users choose a file. Source URL, Git blob SHA, repository and supplied license metadata are retained; these are provenance, not a security or quality endorsement. No repository scripts run, and supporting files/tools are not silently installed. The preview explains that dependencies may make some steps unavailable.

Added skills are bounded writing instructions. Existing evidence, output and tool-permission rules keep priority. A user can edit or remove custom instructions; included guides are preserved. Discovery queries contain public task keywords; no local document uploads. Assistant discovery tools are available only with web research enabled and cannot install skills.
