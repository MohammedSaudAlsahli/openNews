# أدلة الإصدارات / Release evidence

تحتوي هذه الملفات على تقارير البناء والاختبارات الاصطناعية المنشورة سابقًا في Assets. نُقلت إلى هنا لتبقى صفحة التحميل واضحة، مع الاحتفاظ بالقيم الأصلية وبصمات الملفات. بعض الحقول تصف لحظة إجراء الاختبار؛ لا تعني حالة قناة التحديث الحالية. لا تتضمن بيانات مستخدم أو مفاتيح أو قواعد بيانات.

These files preserve previously published build and synthetic QA reports, with original values and asset digests. Reports moved here to keep downloads clear. Fields describe their original validation time, rather than current update-feed state. No user data, keys or databases are included.

- [0.3.2](v0.3.2.json)
- [0.3.1](v0.3.1.json)

المثبّت DMG وحزمة التحديث يحتفظان بالتطبيق نفسه من CI؛ تغيير التغليف لا يغيّر رقم الإصدار أو الوسم أو بيانات التطبيق.

The DMG and updater retain the original CI application. Packaging changes do not move release tags, change app versions or modify user data.
