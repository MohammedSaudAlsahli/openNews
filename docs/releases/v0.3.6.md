# openNews 0.3.6

## العربية

- حسابات مرتبة حسب المزوّد، مع بحث وطرق ربط واضحة بدل أسماء المحولات التقنية.
- تسجيل دخول ChatGPT ظاهر ضمن OpenAI، إلى جانب مفتاح API المستقل.
- دعم Google Cloud OAuth لـGemini عبر Agno وVertex AI، مع متطلبات الإعداد داخل التطبيق. يتطلب مشروع Google Cloud وفوترة وصلاحيات؛ لا يستخدم اشتراك Gemini الشخصي. اختُبر المسار بمحاكاة المزوّد، ولم يُختبر بحساب Google فعلي لعدم توفر إعداد المشروع. [دليل الربط](../accounts.md).
- استشهادات مرقمة تفتح معاينة المصدر، وخطوات عمل تتبع لغة الواجهة.
- مركز قراءة محلي ودعم الوسائط عند الطلب.
- تجهيز الملخصات في أوقات خمول الجهاز وتحرير ذاكرة التوليد بين المهام، مع الحفاظ على النموذج والملخصات المحفوظة.

تبقى بيانات النسخة الرسمية محفوظة ومساحة Dev مستقلة. لأجهزة Apple Silicon وmacOS 14 أو أحدث. الحزمة موقعة محليًا ad-hoc وليست موثقة لدى Apple.

## English

- Searchable provider directory with clear connection methods instead of adapter names.
- ChatGPT browser sign-in under OpenAI, alongside separately billed API-key access.
- Google Cloud OAuth support for Gemini through Agno and Vertex AI, with in-app setup requirements. Requires a billed Google Cloud project and permissions; it does not use a personal Gemini subscription. Tested with a simulated provider, not a live Google account because project registration is unavailable. [Connection guide](../accounts.en.md).
- Numbered source previews and interface-language activity steps.
- Local reading hub and on-demand media.
- Idle-aware summary scheduling and generation-memory release between jobs, preserving the selected model and saved summaries.

The official workspace is retained and Dev remains separate. Apple Silicon, macOS 14 or later. Ad-hoc signed, not Apple-notarized.
