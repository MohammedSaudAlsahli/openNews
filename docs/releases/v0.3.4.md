# openNews 0.3.4

## العربية

اعتماد تحسينات نسخة التطوير المختبرة في إصدار Tauri الرسمي للاستخدام اليومي، لأجهزة Apple Silicon وmacOS 14 أو أحدث.

- **معاينة الروابط:** سطح واضح وحدود مرئية في الوضعين الداكن والفاتح، مع فصل المصدر والمقتطف ورابط فتح الأصل. تبقى المعاينة دون تشغيل نموذج.
- **سجل المقال:** أسطر مضافة ومحذوفة بألوان وعلامات واضحة، وأرقام قبل/بعد، وعدّادات لكل حقل. يمكن إظهار السياق الذي لم يتغيّر وقراءة المقال المحفوظ دون إعادة جلبه أو تلخيصه.
- **النسخة الأولى:** توضيح أن المقارنة تحتاج تحديثًا لاحقًا؛ لا تُعرض النسخة الوحيدة كإضافات مصطنعة.
- **التنقل المصغّر:** شريط أيقونات عند طيّ القائمة، مع تلميحات والصفحة الحالية واستعادة تركيز لوحة المفاتيح. تبقى الكتابة والتنقل المحمي محفوظين.
- **بياناتك:** التحديث الرسمي يحتفظ بمقالاتك ومحادثاتك ومسوداتك وملخصاتك وحساباتك ونماذجك في مساحة openNews الحالية. تبقى مساحة openNews Dev مستقلة.

حمّل DMG واسحب **openNews** إلى Applications، أو استخدم قناة التحديث الموقّعة بعد إتاحتها. لا تحذف مجلد البيانات. الحزمة موقّعة محليًا ad-hoc وليست موثّقة لدى Apple. لا يوجد بناء Intel أو Windows أو Linux معتمد في هذا الإصدار. فصل المكونات لتنزيلها عند الحاجة ما زال اقتراحًا؛ هذا الإصدار لا يغيّر طريقة تثبيت المكتبات.

## English

Promote the tested development interface to the official daily-use Tauri application for Apple Silicon Macs running macOS 14 or later.

- **Link previews:** an opaque surface and visible edge in both themes, with clear separation between source, excerpt and original-link action. Previews still require no model inference.
- **Article history:** clear added/removed rows, before/after line numbers and per-field counts. Reveal unchanged context or read the stored article without refetching or summarizing it.
- **First capture:** explicitly identify a single saved version as a baseline, without inventing additions.
- **Compact navigation:** retain an icon rail when the sidebar is collapsed, with tooltips, current-page indication and keyboard focus restoration. Preserve writing and guarded navigation.
- **Existing data:** official updates retain articles, conversations, drafts, summaries, accounts and models in the current openNews workspace. The openNews Dev workspace remains separate.

Install the DMG application into Applications, or use the signed update channel once available. Do not delete the data folder. The bundle is ad-hoc signed, not Apple-notarized. No supported Intel, Windows or Linux build is included. Download-on-demand components remain a proposal; this release does not change dependency installation.
