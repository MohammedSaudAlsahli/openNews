# OpenStudio 0.2.0 — Experimental preview

Native macOS writing and news workspace. **Apple Silicon, macOS 14 or later.**

- Guided first run: add a source, choose a writing model, then discuss your first story. Every step can be skipped.
- Articles load in small pages as you browse; full reader content and thumbnails load on demand.
- Signed in-app updates through Sparkle, with automatic checks and a manual Check for Updates command.
- Persistent news archive, article versions, related-news search, bilingual summaries and optional local models.
- Quiet background summaries and indexing, thermal/Low Power Mode pauses, and idle model-memory release.
- Improved native conversation, Markdown/code rendering, model selection, and settings.

## Install
Download **OpenStudio-0.2.0-macOS-arm64.dmg**, open it, and drag OpenStudio to Applications.
The app bundles its runtime. You do not need Python, Terminal, or Ollama to start reading.
Local summary models are optional downloads from Settings.

**This preview is not Apple-notarized and has no Developer ID signature.** macOS may block
its first launch. Only proceed if you trust this repository and release; do not disable
Gatekeeper or remove quarantine attributes. See docs/SETUP.md for the supported first-run flow.

## Updates and data
Install this version once to get the updater. Future signed updates replace the app;
your saved news, drafts, connections and downloaded models remain in Application Support.
Automatic checks are periodic, not instant GitHub push notifications. Installation is by
user approval. In-app AI use is optional and provider charges may apply.

## Preview limits
No Intel build in this release. No automatic publishing to social accounts. Local model
quality varies; review summaries and cited evidence. This release does not claim that every
provider/account/model has been live-tested. Embedding workers restart after idle, which can
add latency to the first semantic search.
