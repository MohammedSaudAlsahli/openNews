# OpenStudio 0.2.3 — Experimental preview

This update retrieves missing article text in the background, retries temporary failures, and refreshes article cards after successful reading. A bounded public-page rendering fallback runs while the app is open, outside Low Power Mode and only at nominal thermal state. Publisher restrictions and subscriber-only pages may still prevent extraction.

- Explanatory article summaries and configurable daily news reports.
- Editable assistant defaults and task instructions inside the app, with Markdown preview.
- Writing slash commands and automatic format selection; related news and indexing visibility.
- Preserve cached article text when a concurrent retrieval fails.

407 engine tests and 54 native tests passed locally before packaging. The release pipeline additionally checks the embedded runtime and conversations.

macOS 14+ on Apple Silicon. Experimental, ad-hoc signed and not Apple notarized. Existing installations receive this release through the signed Sparkle update feed; local articles, conversations, settings and downloaded models remain outside the app bundle. The updater downloads the full application archive.

This is the current native macOS app. Tauri migration work is separate and is not included in this release.
