# openNews 0.3.0

نسخة **Tauri هي الإصدار الرسمي والمعتمد** من openNews. واجهة SwiftUI السابقة محفوظة في فرع `swift-legacy`؛ لا تغيّر هذه النسخة بياناتها تلقائيًا.

## الجديد

- واجهة عربية وإنجليزية مُعاد تنظيمها للقراءة والمحادثات والمسودات والإعدادات، مع تحسين لوحة المفاتيح والتركيز وحالات التحميل والخطأ.
- مكتبة Ollama واحدة للمقترح والمتاح والمحمّل؛ تعيين نموذج البحث أو الشرح حسب القدرات من نفس الصفحة مع الاحتفاظ بسياق الاختيار.
- مهارات كتابة قابلة للإضافة والتحرير، واكتشاف عبر skills.sh ومعاينة تعليمات GitHub قبل الاستيراد. الاستيراد نصي ولا يشغّل السكربتات.
- تنظيم الاستدلال المحلي والإلغاء والتعامل مع ضغط الذاكرة والطاقة، مع عرض سبب انتظار العمل الخلفي.
- تحسين حفظ نص المقال ونسبته للمصدر وسجل نسخه، وعرض Markdown والشفرة والنصوص العربية المختلطة بالإنجليزية.
- توثيق عربي رئيسي ومقابل إنجليزي، رخصة MIT، سياسة أمان ومساهمة، ونشر مرتبط بحزمة CI وبصمات SHA-256.

## التثبيت والتحديث

حمّل `openNews-0.3.0-macOS-arm64.zip`، فك الضغط وانقل `openNews.app` إلى Applications. أغلق النسخة السابقة قبل استبدالها، واترك مجلد بياناتها. لمستخدمي Swift: استخدم استيراد مساحة العمل داخل الإعدادات بعد إغلاق التطبيق القديم. يُحافظ على المعرّف التاريخي `com.editorialintelligence.studio.preview` للتوافق، وهو لا يعني أن هذا الإصدار تجريبي.

**المنصة:** Apple Silicon، حد أدنى معلن macOS 14. **التوقيع:** ad-hoc، بلا Apple notarization حاليًا. لا تُرفق النماذج بالحزمة. التحديث عبر GitHub Releases؛ قناة التحديث التلقائي الموقّع لم تُفعّل بعد. النماذج والمصادر الخارجية لها تراخيصها وشروطها.

لا يشكّل هذا الإصدار وعدًا بأداء حراري موحّد أو تدقيق أمان شامل؛ راجع مخرجات المساعد ومصادره.

## English

**Tauri is now the official, supported openNews application.** The previous SwiftUI application is preserved on `swift-legacy`; its data is not changed automatically.

### Changes

- Reorganized Arabic/English reading, conversations, drafts and settings, with refined keyboard/focus and loading/error states.
- One Ollama inventory for suggested, available and downloaded models; capability-aware search/explanation assignment in place while retaining selection context.
- Editable/importable writing skills, skills.sh discovery and GitHub instruction preview. Imports are text-only and execute no scripts.
- Local inference scheduling, cancellation and memory/power handling, with explicit background waiting reasons.
- Improved source-text preservation, article revision history, Markdown/code presentation and mixed Arabic/English text.
- Arabic-first documentation with English equivalents, MIT licensing, security/contribution policies and CI-artifact publication with SHA-256 checksums.

### Install and upgrade

Download `openNews-0.3.0-macOS-arm64.zip`, unzip it and move `openNews.app` to Applications. Quit before replacing an earlier app and keep its data directory. Swift users can import their original workspace in settings after quitting the older app. The historical `com.editorialintelligence.studio.preview` identifier remains for compatibility and does not describe this release as experimental.

**Platform:** Apple Silicon, declared minimum macOS 14. **Signing:** ad-hoc, currently without Apple notarization. Models are not bundled. Updates use GitHub Releases; the signed automatic-update channel is not activated. External models and sources retain their own terms.

This release does not promise uniform thermal performance or a comprehensive security audit. Review assistant output and original sources.
