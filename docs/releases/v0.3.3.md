# openNews 0.3.3

## العربية

إصدار Tauri الرسمي للاستخدام اليومي، لأجهزة Apple Silicon وmacOS 14 أو أحدث.

- **openNews** هو التطبيق الرسمي؛ تبقى مقالاتك ومحادثاتك ومسوداتك وملخصاتك وحساباتك ونماذجك في مساحتها الحالية.
- **openNews Dev** للتطوير: اسم ظاهر مختلف، معرّف ومساحة مستقلة، وقناة التحديث الرسمي معطّلة فيه. البناء المحلي افتراضيًا للتطوير.
- `main` للإصدار المعتمد، و`develop` للتعديلات. تحديثات المكتبات تمر باختبارات إلزامية قبل الدمج وتحذف فروعها بعده.
- تحديث Pillow إلى 13.0.0 وfilelock إلى 4.2.4 لمعالجة التنبيهات الأمنية الحالية.
- إزالة ملفات Swift والشعارات والأدوات القديمة من المسار النشط، وتصحيح الهوية وروابط الدعم، وتبسيط تنزيلات الإصدار إلى DMG وبصمته وحزمة التحديث الموقّعة.
- يحتفظ الإصدار بميزات 0.3.2: ملخص محفوظ مع اسم المودل ووقت الحفظ، إعادة التلخيص حسب الطلب مع إبقاء النتيجة السابقة، ومعاينات الروابط عند المرور أو التركيز.

حمّل DMG واسحب **openNews** إلى Applications. لا تحذف مجلد البيانات. التوقيع محلي ad-hoc؛ الحزمة ليست موثّقة لدى Apple. لا يوجد بناء Intel أو Windows أو Linux معتمد في هذا الإصدار.

## English

Official daily-use Tauri release for Apple Silicon Macs running macOS 14 or later.

- **openNews** retains the existing article, conversation, draft, summary, account and model workspace.
- **openNews Dev** has a distinct visible name, application identifier and workspace. Official updates cannot replace it. Local builds default to development.
- `main` is official; `develop` receives changes. Dependency branches require passing checks before automatic merge and are deleted afterward.
- Update Pillow to 13.0.0 and filelock to 4.2.4 for current security advisories.
- Remove obsolete Swift-era files, correct branding/support links and provide a clear DMG download with checksums and signed updater assets.
- Retain 0.3.2 persisted summaries, model/time provenance, on-demand regeneration preserving the previous result and accessible link previews.

Install the DMG application into Applications without deleting its data folder. The bundle is ad-hoc signed, not Apple-notarized. No supported Intel, Windows or Linux build is included.
