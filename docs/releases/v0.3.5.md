# openNews 0.3.5

## العربية

اعتماد إصلاحات الملخصات والتنقل في نسخة Tauri الرسمية للاستخدام اليومي، لأجهزة Apple Silicon وmacOS 14 أو أحدث.

- **الملخصات المحفوظة:** تتطابق حالات بطاقات الأخبار والعدادات مع الملخص الموجود في القارئ. تستعاد الملخصات القديمة المطابقة للمصدر واللغة مرة واحدة دون تشغيل النموذج، مع الاحتفاظ بالنص والمودل ووقت الحفظ المعروف.
- **تغيير المودل:** يبقى الملخص الصالح محفوظًا عند اختيار مودل جديد للمقالات القادمة. زر إعادة التلخيص يستخدم المودل المختار عند طلبك؛ تغيّر محتوى المقال أو لغة الملخص قد يتطلب تحديثه.
- **انتظار الموارد:** لا تظهر رسالة انتظار الذاكرة أو الحرارة فوق ملخص جاهز. تستمر حماية الجهاز للعمل المتبقي دون تعطيل قراءة النتائج المحفوظة.
- **نافذة الماك:** منطقة مستقلة لأزرار النافذة فوق فواصل القوائم، مع توافق مظهر الشريط الأصلي مع ثيم التطبيق.
- **الشريط المصغّر:** محاذاة ومسافات متسقة، وتلميحات صغيرة مناسبة للثيم، وتركيز واضح بلوحة المفاتيح. حركات قصيرة لتفاعل المؤشر، مع احترام تقليل الحركة والتنقل الفوري بلوحة المفاتيح.

يحتفظ التحديث ببيانات مساحة openNews الحالية؛ تبقى مساحة openNews Dev مستقلة. الحزمة موقعة محليًا ad-hoc وليست موثقة لدى Apple. هذا الإصدار مخصص لـApple Silicon، وليس Intel أو Windows أو Linux.

## English

Promote saved-summary and navigation fixes to the official daily-use Tauri application for Apple Silicon Macs running macOS 14 or later.

- **Saved summaries:** article cards and coverage counts agree with the reader. Reconcile source- and language-matching legacy results once without inference, preserving prose, generating model and known creation time.
- **Model selection:** choosing a future model retains valid saved results. Explicit regeneration uses the selected model; changed article content or summary language can require an update.
- **Resource waits:** memory and thermal waiting messages no longer appear above a ready summary. Resource protection still applies to remaining work without blocking saved results.
- **macOS chrome:** reserve window-control space above navigation dividers and match the native window appearance to the app theme.
- **Compact navigation:** consistent alignment and spacing, small theme-matched tooltips and clear keyboard focus. Restrained pointer feedback respects reduced motion; keyboard navigation remains immediate.

Updates retain the existing official workspace; openNews Dev stays separate. The bundle is ad-hoc signed, not Apple-notarized. This release supports Apple Silicon, not Intel, Windows or Linux.
