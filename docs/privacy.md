# الخصوصية وحدود الأمان

تُحفظ كتابات المستخدم والمسودات والمحادثات والأدلة والأخبار والاشتراكات والمهام محليًا في SQLite. يمكن الكتابة وحفظ المسودات وقراءة المواد المحفوظة دون اتصال. وجود البيانات على الجهاز لا يعني أن الرد بالذكاء الاصطناعي يعمل دون إرسال خارجي.

إضافة رابط في بيانات نص مستورد تحفظه كمرجع فقط. أما إضافة **اشتراك أخبار** فهي طلب صريح لمتابعة الرابط: يجلب التطبيق RSS أو Atom، ويبحث عن الخلاصة المعلنة إذا أُدخل رابط موقع، ويستخدم خلاصة Reddit العامة عند إضافة مجتمع. يحاول كذلك قراءة المقالات المرتبطة بالأخبار. المتابعة مفعلة عند الإضافة، ويمكن إيقاف الاشتراك. تعمل ما دام التطبيق يعمل، حتى بعد إغلاق نافذة التحرير إلى شريط القوائم. يفحص المستحق عند تشغيله مجددًا، ولا يعمل بعد اختيار «إنهاء التطبيق».

طلبات الأخبار لا تستخدم cookies أو جلسات متصفح أو بيانات دخول أو مفاتيح مزودي النماذج، ولا تتجاوز حظر Reddit أو تسجيل الدخول أو جدار الدفع. يمنع النقل عناوين الشبكات الخاصة والمحلية، ويفحص إجابات DNS وكل إعادة توجيه، ثم يثبت الاتصال بعنوان IP الذي فُحص مع التحقق من اسم الخادم في TLS. توجد حدود زمنية وحجمية، ورفض لبنى XML الخطرة. إذا تعذر استخراج المقال، يبقى الملخص مع بيان أنه ليس النص الكامل. خادم الأخبار يرى طلب القراءة وعنوان الاتصال الشبكي المعتاد.

قبل إرسال طلب المحادثة، تعرض الواجهة اتصال النموذج وخيارات إرفاق الأخبار والمسودة وموافقة استخدام النموذج والتكلفة. الموافقة خاصة بالنقاش الجاري وإعداداته؛ تبقى مفعلة للرسائل التالية ضمن النطاق نفسه، وتُصفّر عند فتح محادثة أخرى أو تغيير النموذج أو الصيغة أو المدة أو خيارات السياق والمراجع والقواعد المعتمدة. تتضمن البيانات المرسلة الرسالة، جزءًا محدودًا من المحادثة السابقة، المسودة عند اختيار إرفاقها، الأخبار المحددة أو المختارة ضمن الفترة، أمثلة الأسلوب المصرح بها والقواعد المعتمدة. لا يرسل تحديث الأخبار هذه المواد إلى النموذج تلقائيًا. التحليل المحلي لا يرسل بيانات؛ تحليل النص بالنموذج يحتاج موافقة منفصلة. الحقوق `unknown` تمنع اعتماد النص كعينة أسلوب أو إرساله في مسار التحليل الخارجي.

«كتاباتي» منفصلة عن الأخبار. استخدام أمثلة الكتابة هنا تكييف للأسلوب داخل سياق الطلب، وليس تدريبًا أو fine-tuning، ولا يحول الأخبار إلى تفضيلات دائمة. حفظ قاعدة أسلوب يتطلب موافقة صريحة. الأخبار والملخصات وكتابات الأسلوب والردود السابقة بيانات غير موثوقة، وليست تعليمات نظام. لا يملك Agent تصفحًا حرًا أو أدوات شل أو ملفات أو قراءة مفاتيح؛ جلب الأخبار ينفذه مكوّن الاشتراكات المحدود خارج النموذج. هذا لا يضمن صحة النص الناتج؛ الاستشهاد بالمصدر لا يعني تحققًا مستقلًا من ادعاءاته.

بطلب المستخدم، يحفظ Swift بيانات اعتماد كل اتصال في ملف JSON داخل `~/Library/Application Support/com.editorialintelligence.studio/default/.providers/<connection-id>.json`. المجلد بصلاحية 0700 والملف 0600، والكتابة ذرية مع رفض الروابط الرمزية. هذه ملفات نصية محلية غير مشفرة، ويمكن فتحها من الإعدادات. لا يعدّل التطبيق مجلدات `.claude` أو `.codex` ولا يستورد مفاتيحها. المفاتيح لا تعبر IPC ولا تُحفظ في SQLite أو سجلات الطلبات أو حزمة التطبيق. مفاتيح Keychain القديمة تحتاج إعادة حفظ يدوي؛ لا توجد هجرة تلقائية لها.

تحديث أدلة النماذج يتصل بالمزود باستخدام بيانات اتصالك دون إرسال النصوص التحريرية. المصادر العامة لا تتلقى مفتاح مزود آخر. تُحفظ القائمة والتوقيت وآخر خطأ عام محليًا، ولا تُعرض نصوص استثناءات SDK الخام. تبقى جميع مهايئات Agno الـ68 ممثلة؛ نجاح قراءة دليل لا يثبت صلاحية توليد المحتوى بكل نموذج. إعدادات API لا تقبل بيانات دخول ضمن الرابط أو query أو fragment، وHTTP لمزودي النماذج مسموح لخادم loopback فقط.

لا توجد telemetry من Agno، أو نشر مباشر، أو مزامنة سحابية تلقائية. البرنامج ليس داخل App Sandbox في هذه المرحلة، ولا تحمي صلاحيات الملفات من برنامج ضار يعمل بصلاحيات المستخدم نفسه. Skills وتشغيل سكربتاتها غير مفعلة.

الإلغاء يمنع اعتماد نتيجة جديدة بعد إلغائها؛ لا يضمن استرجاع تكلفة طلب وصل للمزود. الاستئناف الخارجي يحتاج موافقة لأنه قد يكرر الطلب. لا يوجد تسعير نقدي آلي موثوق. لحفظ نسخة يدوية، أغلق التطبيق وانسخ مجلد مساحة العمل كاملًا مع الانتباه إلى احتوائه ملفات الاعتماد المحلية. واجهة النسخ الاحتياطي المشفر والحذف الكامل غير موجودة بعد.
