# الخصوصية والبيانات

[English](privacy.en.md) · [التوثيق](README.md)

تُحفظ قاعدة SQLite والمقالات والمحادثات والمسودات والإعدادات في مساحة التطبيق المحلية، خارج حزمة `.app`. راجع مسارها في [دليل الاستخدام](SETUP.md). لا ترفعها إلى GitHub. لا تُحذف البيانات بمجرد استبدال التطبيق.

| الميزة | ما يتصل بالشبكة؟ |
|---|---|
| قراءة المحفوظات والمسودات | تعمل على البيانات المحلية الموجودة |
| جلب الأخبار والأصل والصور | طلبات للمصدر وخدماته اللازمة |
| دليل المصادر والمهارات | خدمات الدليل، مثل RSS.mobi وskills.sh وGitHub، وتتلقى الاستعلام اللازم |
| نموذج محلي | Ollama المحلي؛ تنزيل البرنامج/الأوزان يحتاج الشبكة |
| حساب نموذج سحابي | مزوّد الحساب يستقبل السياق المختار لإتمام الطلب، وفق سياسته وأسعاره |
| الإصدارات والتشخيص | GitHub عند التحقق/التصفح؛ راجع تقرير التشخيص قبل إرساله |

تُحفظ بيانات اعتماد الاتصال في ملفات خاصة بمساحة المستخدم؛ لا نفترض أنها مشفّرة بتشفير قرص مستقل أو أن النماذج السحابية محلية. تعطيل telemetry الخاص بـAgno لا يعني عدم وجود أي اتصال شبكي في التطبيق.

تُستورد المهارات كتعليمات نصية؛ لا تُشغّل سكربتات المصدر ولا تُمنح صلاحيات إضافية تلقائيًا. استيراد مساحة Swift ينسخ بياناتها بما فيها حسابات الاتصال؛ لا تشارك النسخة الاحتياطية.

للإبلاغ عن ثغرة أو تسريب استخدم [سياسة الأمان](../SECURITY.md). لا ترسل أسرارًا أو قواعد بيانات فعلية لإعادة إنتاج خلل.
