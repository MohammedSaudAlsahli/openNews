# بناء الحزمة

[English](packaging.en.md) · [إجراءات الإصدار](RELEASING.md)

ينفّذ `bash scripts/build_app.sh` توليد كتالوج المزوّدين، وتصدير اعتماد Python المقفل، وتجهيز CPython قابل للنقل واعتماداته، وترجمة خدمات macOS الصغيرة، ثم بناء واجهة Tauri. المستخدم النهائي لا يحتاج أدوات التطوير أو Python خارجيًا.

تُوقّع الملفات الأصلية المضمّنة من الداخل إلى الخارج بتوقيع ad-hoc. تتأكد CI من توقيع الحزمة ومن تشغيل محركها المنقول في مجلد مؤقت، ثم تحفظ ZIP مع الأذونات والروابط الرمزية وبصمته وبيانات البناء. لا تشمل الحزمة قواعد بيانات المستخدم أو المفاتيح أو النماذج.

ناتج التطبيق: `desktop/src-tauri/target/release/bundle/macos/openNews.app`. يستخدم التوزيع الحالي مشغّل macOS Apple Silicon. الحد الأدنى المعلن 14.0؛ لا يوجد بناء Intel معتمد.

التوقيع المحلي ليس Apple Developer ID أو notarization. تذكر ملاحظات الإصدار هذا القيد دون وصف الإصدار الرسمي بأنه تجريبي. تحتاج هوية Apple وتوثيقها إعدادًا منفصلًا؛ لا تستخدم سكربتات Swift التاريخية لنشر Tauri. راجع [التغليف القديم](legacy/packaging.md) فقط عند صيانة فرع Swift.
