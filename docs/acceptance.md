«أخبار الأسبوع» تعتمد تاريخ النشر المعروف خلال آخر سبعة أيام، وبحد أقصى 12 مادة في سياق الطلب. تعرض قائمة الأخبار 100 مادة حديثة من المخزون المحلي؛ لا تعني هذه الحدود تغطية كل الأخبار أو كل المقالات. تاريخ الاكتشاف ليس تاريخ النشر، وتاريخ النشر ليس بالضرورة تاريخ الحدث. الروابط والإسناد دليل على المواد المستخدمة، لا تحقق مستقل من صحة الوقائع.

# سجل التحقق — 11 أكتوبر 2026

**حالة التسليم: M0 تجريبي. مواصفات MVP/V2/V3 لم تكتمل.** الاختبارات أدناه محلية وليست شهادة قبول للمنتج النهائي.

## نتائج ناجحة

- **96 اختبار Python**: استيراد 20 عنصرًا وإعادة الاستيراد، تحليل العنصر المتغير فقط، اعتماد/سحب DNA، المسودات/التعديل/التصدير باستجابات نموذج اصطناعية، رفض أدلة مختلقة، الحقوق وموافقة الإرسال، حقول الأسرار، المهام والإلغاء المبكر، الفهرس العربي/الإنجليزي، sqlite-vec، 68 مدخلًا في دليل المزودين، المهايئات دون شبكة، وsocket حقيقي بحدود الرسائل وعزل مساحة العمل.
- **4 اختبارات Swift Testing**: decoding عقد الصحة، إزاحات المقتطف العربي مع التشكيل، بروتوكول الطلب وUUID، ورفض الرسالة الكبيرة قبل الاتصال.
- **حزمة مستقلة محليًا**: تشغيل Python من نسخة منقولة من `.app` ببيئة خالية من مسارات التطوير، SQLite 3.53.1 وsqlite-vec 0.1.9، استيراد/تحليل/دليل/اعتماد DNA، ثم تنظيف socket عند الإغلاق.
- **توقيع محلي**: اجتياز `codesign --verify --deep --strict` بتوقيع ad-hoc. هذا ليس Developer ID أو notarization.
- **واجهة حقيقية**: فتح التطبيق، اتصال المحرك، استيراد «مثال تجريبي — الكتابة الواضحة»، ظهوره في المكتبة، التحليل المحلي، بطاقة السؤال مع مقتطفها، اعتماد DNA، ثم سحب اعتماد القاعدة. لا تبقى قاعدة الاختبار فعالة كتفضيل للمستخدم. الحزمة لا تشمل قاعدة مزروعة.
- **AgentOS spike**: صحة HTTP 200 عبر FastAPI TestClient مع lifespan. القرار النهائي IPC محلي؛ انظر ADR-001.

## فشل وقبول غير مكتمل

نجح إنشاء وحذف عنصر Keychain اصطناعي من Swift، لكن قراءته من Python المضمّن أعادت `errSecAuthFailed (-25293)` في سياق أداة التنفيذ رغم قائمة الثقة المحددة. لم توسع صلاحيات السلسلة ولم تستخدم تخزينًا نصيًا بديلًا. عُطلت المطالبات التفاعلية داخل المحرك كي يفشل سريعًا بدل تعليق المهمة في نافذة نظام مخفية. **مسار مفاتيح API ليس مقبولًا للإطلاق.** لا ننسب السبب يقينًا إلى توقيع ad-hoc أو سياق التشغيل دون تحقق إضافي. أزيلت عناصر الاختبار الاصطناعية.

لا توجد شهادة Developer ID صالحة. لم تنفذ notarization، أو اختبارات حسابات OpenAI/Anthropic الحية، أو تجربة Mac نظيف، أو تشغيل نموذج محلي فعلي.
