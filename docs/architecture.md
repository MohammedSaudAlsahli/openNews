# معمارية openNews

[English](architecture.en.md) · [التوثيق](README.md)

نسخة Tauri هي المعتمدة. التصميم السابق محفوظ في [فرع Swift](https://github.com/MohammedSaudAlsahli/openNews/tree/swift-legacy).

```text
React / TypeScript → Tauri / Rust → Unix socket → Python / Agno → SQLite
                           ↓                          ↓
                    macOS helpers              Ollama / chosen providers
```

- `desktop/src`: العرض والتنقل والحالات العابرة، العربية/الإنجليزية، القارئ والمحادثات والإعدادات. لا يقرأ المتصفح ملفات الاعتماد مباشرة.
- `desktop/src-tauri/src`: دورة حياة المحرك، أوامر IPC المسموح بها، الحوارات الأصلية، الروابط الخارجية والتشخيص والتحديث. الويب الخارجي للقراءة منفصل عن واجهة التطبيق.
- `desktop/native`: أدوات Swift صغيرة لخدمات النظام وWebKit، وليست واجهة SwiftUI القديمة.
- `engine/eis_engine`: الأخبار والمحادثات والمسودات والتعليمات والمهارات والنماذج والمهام. المحرك مصدر الحقيقة للبيانات المحفوظة.
- `SQLite`: قاعدة محلية مع نسخ للمحتوى وحالة المهام؛ النماذج المحمّلة ليست داخل قاعدة البيانات.

يبدأ Rust عملية Python مضمّنة ببيئة محدودة ووضع معزول، ويتصل بها عبر Unix socket خاص. يحمي قفل مساحة العمل من فتحها بمحركين. تستخدم الرسائل معرّف طلب وإصدار مخطط وحدود حجم. تنتهي العملية عند الخروج؛ إغلاق النافذة وحده يترك التطبيق في شريط القائمة.

تشترك عمليات embedding والشرح المحلية في تنظيم الاستدلال وحدود الأداء. تُراقب الطاقة والحرارة وضغط الذاكرة لتأجيل العمل الخلفي. تُفصل قائمة النماذج المحمّلة عن تعييناتها: embedding للبحث، والتوليد للشرح. لا توجد دعوى أن كل نموذج يعمل لكل وظيفة.

المقالات والمهارات وHTML بيانات غير موثوقة. تقيد طبقة الجلب الروابط العامة والتحويلات؛ يمر العرض عبر تنقية HTML. استيراد المهارات لا ينفّذ مستودعاتها. استخدام مزوّد سحابي ينقل السياق اللازم إلى ذلك المزوّد.

الفحوصات مقسمة إلى pytest للمحرك، وVitest للواجهة، واختبارات Rust للجسر والاستمرارية والتحديث الموقّع الاصطناعي. [QA الأصلي](../desktop/qa/README.md) يتحقق من استخدام الواجهة في مساحة منفصلة. مرور هذه الفحوصات ليس إثباتًا لأداء كل جهاز أو تدقيق أمني شامل.

## أسماء التوافق

تحتفظ النسخة الحالية بمعرّف `com.editorialintelligence.studio.preview`، وحزمة Python الداخلية `eis_engine`، وبعض أسماء التنفيذ وموقع مفتاح التحديث التاريخية. هذه مراجع تشغيل وتوافق فعلية وليست تطبيقات قديمة إضافية. تغييرها تجميليًا قد يفصل البيانات أو يقطع التحديثات. مصدر عقود IPC هو `engine/eis_engine/contracts.py`؛ لا تُحفظ نسخ JSON مولّدة غير مستخدمة منها.
