# لغة خطوات العمل ومراجع المحادثة

[English](chat-references.en.md) · [التوثيق](README.md)

يتبع وصف خطوات العمل لغة الواجهة المختارة في الإعدادات، حتى عند كتابة السؤال بلغة أخرى. لغة الإجابة مستقلة وتبقى حسب الطلب وتعليمات المساعد. تبقى عبارات البحث وأسماء المصادر كما استُخدمت فعليًا.

يستخدم عرض خطوات العمل الترجمة المحفوظة بالعربية أو الإنجليزية. لا يؤدي تغيير لغة الواجهة إلى إرسال طلب جديد للمودل. إذا لم توجد ترجمة لسجل قديم، يعرض التطبيق أن الوصف غير متاح بهذه اللغة، مع إبقاء خطوات الأدوات الفعلية ظاهرة.

المعرّف الطويل بين الأقواس مرجع داخلي للمصدر، وليس جزءًا من الخبر. يعرضه التطبيق داخل رد المساعد كرقم صغير يفتح معاينة: اسم الموقع، عنوان المصدر، تاريخ نشره ومقتطفه المحفوظ إن توفرا، ورابط فتح الأصل. يتكرر الرقم نفسه للمصدر نفسه. تظهر المراجع غير المعروفة بوصفها غير متاحة، ولا يخمّن التطبيق عنوانًا أو رابطًا لها.

تعمل المعاينة من بيانات المرجع المحفوظة دون جلب صفحة أو تشغيل مودل. المقتطف لا يعني قراءة المقال كاملًا أو التحقق المستقل من ادعاءاته. تظل قائمة المصادر أسفل الرد متاحة. يضم نسخ الرد أرقامًا مقروءة وعناوين المصادر وروابطها؛ وتبقى أمثلة الكود والروابط المكتوبة أصلًا دون تغيير.

افتح رقم المصدر بالنقر أو Enter أو Space، وأغلق المعاينة بـ Escape للعودة إلى المرجع. يستخدم العرض الثيمين الفاتح والداكن، واتجاه الواجهة المختار، مع بقاء نص المصدر باتجاهه الأصلي.
