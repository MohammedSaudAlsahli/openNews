# إعادة تصميم مساحة الكتابة

11 أكتوبر 2026 — تنفيذ فعلي في تطبيق SwiftUI، وليس نموذج واجهة منفصلًا.

اختار المستخدم أن تبدأ التجربة بكتابة المحتوى ومراجعته، وتبقى المصادر بجانبه. لذلك استُبدلت الصفحات الست بمساحة واحدة: محرر دائم ولوحة «المصادر / أسلوبي»، مع قائمة صغيرة للمسودات وإعدادات macOS منفصلة.

## ما تغير

| سابقًا | الآن |
|---|---|
| نظرة عامة وإحصاءات قبل العمل | محرر مفتوح فورًا |
| المصدر، التقنية وDNA في صفحات متفرقة | المصدر، اقتباسه واعتماد قاعدته داخل اللوحة نفسها |
| الكتابة تبدأ بإعداد نموذج وقاعدة أسلوب | كتابة وحفظ يدوي محلي فورًا؛ المساعدة بالنموذج اختيارية |
| فتح المسودة داخل نافذة عائمة | تحرير المسودة في مساحة العمل مع مراجعة قابلة للإظهار |
| إعدادات كثيرة في التنقل الرئيسي | إعدادات أصلية بـ⌘, وخيارات إضافية قابلة للطي |
| ألوان ثابتة ووضع فاتح مفروض | ألوان النظام مع اختيار تلقائي/فاتح/داكن للتطبيق |
| أسماء تقنية مثل DNA وAgno | «أسلوبي»، «اقتراحات لأسلوبك»، «مساعدة في الكتابة» |

التنقل إلى مسودة أخرى يحمي النص غير المحفوظ. الحفظ أثناء الانتقال يمنع الكتابة مؤقتًا حتى تنتهي العملية القصيرة. التصدير يحفظ التعديلات أولًا ويحتفظ بتنبيه المراجعة. اكتمال التوليد مرتبط بمعرّف المهمة الصحيح، ولا يُستدل عليه من مجرد ظهور أي مسودة جديدة.

## عمل الوكلاء الخمسة

1. **Apple UX:** إرشادات Apple الرسمية وتحويلها إلى تنقل وأدوات أصلية.
2. **Mobbin والمراجع:** الأنماط العامة المتاحة، ومقارنتها بـiA Writer وUlysses؛ نفّذ نوافذ الاستيراد والمساعدة.
3. **تدفق العمل:** تتبع عقود البيانات وحالات التعطل؛ نفّذ لوحة المصادر والأسلوب.
4. **العربية وإمكانية الوصول:** اللغة، اتجاه النص، الحالات والألوان؛ نفّذ إعدادات النماذج.
5. **المراجعة المستقلة:** راجع المصدر والواجهة الحقيقية، ورصد حالات فقد التعديلات وربط نتائج التوليد؛ وثّق التصميم المبني.

التقارير التفصيلية في [design-research](design-research/). نُفذت الملاحظات وجُمعت في التطبيق نفسه.

## المراجع المباشرة وكيف استُخدمت

- [Apple: Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars): إجراءات متكررة في شريط أدوات أصلي مع اختصارات وقوائم مكافئة.
- [Apple: Panels](https://developer.apple.com/design/human-interface-guidelines/panels): معلومات المصدر والأسلوب بجوار المهمة الحالية.
- [Apple: Disclosure controls](https://developer.apple.com/design/human-interface-guidelines/disclosure-controls): إظهار التفاصيل والخيارات الثانوية عند الحاجة.
- [Apple: Settings](https://developer.apple.com/design/human-interface-guidelines/settings): نافذة إعدادات مستقلة بدل وجهة دائمة في التنقل.
- [Apple: Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) و[Writing](https://developer.apple.com/design/human-interface-guidelines/writing): تسميات واضحة، نص عربي مباشر، حالات تُفهم بالنص والرمز.
- [Mobbin: Sidebar](https://mobbin.com/glossary/sidebar) و[Segmented control](https://mobbin.com/glossary/segmented-control): لوحة مساندة وتبديل محدود بين المصادر والأسلوب. هذه إرشادات عامة قُرئت مباشرة؛ مجموعات شاشات التطبيقات المحمية بتسجيل الدخول لم تُفحص.
- [iA Writer: Library navigation](https://ia.net/writer/support/library/navigation) و[Ulysses: Sheets and groups](https://help.ulysses.app/567894-sheets-groups): استُخدما كمرجع لتنظيم النصوص والمراجع حول الكتابة. التطبيق لا ينسخ شاشاتهما.

هذه ترجمة للإرشادات إلى قرارات هذا المنتج، وليست ادعاء اعتماد من Apple أو Mobbin.

## تحقق التنفيذ

- نجح **96 اختبار Python و4 اختبارات Swift**. أضيفت اختبارات للنص الكامل وإسناد الاقتراحات إلى المصدر/النسخة الصحيحين، والمسودة اليدوية دون نموذج، وتصحيح الحقوق دون تكرار النسخة.
- اجتاز البناء والتحقق من التوقيع المحلي وصورة DMG واختبار المحرك المضمّن بعد نقل الحزمة.
- نجح اختبار أصلي فعلي لكتابة مسودة عربية وحفظها بـ⌘S، مراجعة المصدر بجانبها، اعتماد قاعدة ثم سحبها، وحفظ التعديلات قبل الانتقال بـ⌘N، وإعادة فتحها بـ⌘O.
- صُدّرت المسودة التجريبية عبر نافذة macOS إلى Markdown وقُرئ الملف للتأكد من النص وتنبيه المراجعة.
- عاين المراجع المستقل حالة المسودة العربية المحفوظة مع تفاصيل المصدر في الوضع الداكن. عاين المنفذ المحرر والإعدادات في الوضع الفاتح، ثم أعاد المظهر إلى إعداد النظام.
- النسخة التجريبية المحفوظة في مساحة العمل تحمل اسم «تجربة الواجهة — الكتابة الواضحة». أُعيد سحب قاعدة الأسلوب التجريبية؛ الحزمة لا تتضمن قاعدة بيانات المستخدم.

المراجعة لا تعادل دراسة استخدام بشرية، أو اختبار VoiceOver شامل، أو تحققًا من كل حجم نافذة. حد 900×640 مُعلن في الكود. لم تُنفذ مكالمة نموذج حقيقية. مشكلة قراءة مفتاح API من Keychain والتوثيق لدى Apple ما زالتا موثقتين في [سجل القبول](acceptance.md).

| الإجراء | الاختصار |
|---|---|
| مسودة جديدة | ⌘N |
| المسودات المحفوظة | ⌘O |
| حفظ نسخة | ⌘S |
| إضافة مصدر | ⌘⇧I |

## تنسيق القراءة، مكتبة المصادر واللغة — 2026-10-12

- قارئ Markdown أصلي مشترك للمحادثة والمقالات وقارئ شريط القوائم وكتابات المرجع؛ يدعم العناوين والقوائم والاقتباسات والتغليظ والكود. الروابط ملوّنة وتحتها خط، والنقر يفتح HTTP/HTTPS فقط. لا يحمّل صورًا خارجية ولا يشغّل HTML.
- استخراج المقال يحافظ على العناوين وروابط الناشر؛ التحديث اليدوي يعيد استخراج المواد القديمة ضمن حد 50 مادة للخلاصة ويحافظ على النص السابق عند فشل الجلب. الملخص ووصف الحلقة يبقيان موسومين بحالتهما.
- «مكتبة المصادر» دليل محلي من 12 خلاصة عربية/إنجليزية اختُبرت مباشرة في 2026-10-12، مقسّمة إلى عامة وأخبار وتقنية وذكاء اصطناعي وعلوم وأعمال ورياضة وبودكاست. بحث وتصنيف ولغة، إضافة بضغطة، علامة للمضاف واستئناف المتوقف. لا يُنشأ اشتراك بمجرد فتح المكتبة.
- مصادر الدليل روابط RSS الرسمية للناشر أو مضيف البودكاست؛ تعرض رابط الخلاصة والناشر وتاريخ الفحص. تُنسخ القائمة الأولية إلى ملف YAML قابل للتعديل مرة واحدة؛ المحتوى نفسه يتحدث وفق جدول الاشتراكات. يدعم الإدخال اليدوي اكتشاف RSS من الموقع إذا أعلن عنه، وRSS/Atom وReddit.
- الإعدادات مقسّمة إلى عام/الاتصالات/الوكلاء؛ العربية والإنجليزية واتجاه الواجهة يتغيران من «عام» دون إعادة إنشاء المسودة. لا يُترجم نص المستخدم أو الأخبار أو مخرجات النموذج عند تبديل لغة الواجهة.

### ملف المصادر القابل للتعديل

المكتبة الافتراضية في `engine/eis_engine/feed_library.yml`. عند فتح المكتبة أول مرة تُنسخ إلى `sources.yml` بجانب قاعدة مساحة العمل؛ لا تستبدل تحديثات التطبيق تعديلات المستخدم. زر **تعديل ملف المصادر** يفتح النسخة المحلية في محرر macOS الافتراضي، و**إعادة تحميل** يقرأ التعديلات. تظهر التصنيفات الجديدة تلقائيًا. تعديل الدليل لا يضيف اشتراكات ولا يحذف الاشتراكات السابقة؛ تبدأ المتابعة عند ضغط إضافة.

واجهة التطبيق SwiftUI وAppKit أصلية: TabView وForm وList وNSTextView وألوان النظام. تحديد التصنيفات يستخدم List الأصلية؛ المظهر يختار حسب النظام أو فاتح/داكن من عام. قارئ Markdown مبني بعناصر Text الأصلية، دون WebView أو واجهة HTML.
