# Activity language and conversation references

[العربية](chat-references.md) · [Documentation](README.en.md)

Public activity descriptions follow the interface language selected in settings, even when the question uses another language. Answer language remains independent and follows the request and assistant instructions. Actual search queries and source names remain verbatim.

The activity display selects the saved Arabic or English translation. Switching interface language does not send a new model request. If an older record lacks a translation, the interface explains that the description is unavailable in that language while retaining its actual tool steps.

A long bracketed identifier is an internal source reference, not part of the news. Assistant prose displays it as a small numbered button opening a preview: hostname, source title, publication date and saved excerpt when available, and an original-source link. Repeated references share a number. Unknown references are explicitly unavailable; the app does not invent titles or addresses.

Previews use saved reference metadata without fetching a page or running a model. An excerpt does not imply full-article reading or independent verification. The source list below the answer remains available. Copying the answer includes readable numbers, source titles and URLs, while retaining code examples and existing Markdown links.

Open a source number by click, Enter or Space; Escape closes the preview and restores focus to the reference. Both themes and interface directions are supported, while source text keeps its own reading direction.
