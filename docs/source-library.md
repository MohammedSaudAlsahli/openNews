# اكتشاف المصادر وإدارتها

افتح **اكتشاف المصادر** من الشريط الجانبي:

- **اكتشاف** يعرض دليل RSS.mobi مع البحث والتصنيفات وتحميل المزيد. المتابعة اختيارية؛ لا يضيف التطبيق الدليل كله إلى اشتراكاتك.
- **مصادري** يعرض جميع اشتراكاتك الفعلية، بما فيها الروابط المضافة يدويًا ومجتمعات Reddit والمصادر المتوقفة مؤقتًا. العدد على التبويب هو عدد الاشتراكات، والعدد بجوار البحث هو عدد النتائج المطابقة.
- **إضافة رابط** يفتح نموذج إضافة المصادر الحالي، بما فيه RSS وروابط المواقع وReddit وRSS لحسابات X عبر خدمة تحويل.

## إلغاء المتابعة

في **مصادري** اضغط **إلغاء المتابعة** بجوار المصدر، ثم أكّد اسم المصدر. تتوقف الأخبار الجديدة وتبقى المقالات السابقة والمحفوظة. يمكنك متابعة المصدر مجددًا من الدليل أو بإضافة رابطه.

داخل تبويب **اكتشاف** افتح قائمة **تتابعه** للوصول إلى الإجراء نفسه.

## إدارة مصدر

من قائمة **تتابعه** أو **متوقفة مؤقتًا**:

- **إيقاف مؤقت** يوقف الجلب الدوري مع إبقاء المصدر في مصادري.
- **استئناف المتابعة** يعيد تشغيله ويطلب تحديثًا في الخلفية.
- **تحديث الآن** يطلب جلب الأخبار للمصدر النشط؛ لا يعني ظهور رسالة بدء التحديث أن الجلب انتهى بنجاح.
- **إلغاء المتابعة** يزيل المصدر من قائمة الاشتراكات دون حذف مقالاته.

تعرض مصادري عدد الأخبار غير المقروءة وآخر جلب ناجح والخطأ عند تعذّر التحديث. يمكن البحث بالاسم أو الرابط، والترتيب أبجديًا، والتصفية حسب المصادر النشطة أو المتوقفة أو التي تحتاج انتباهًا. إغلاق التطبيق يوقف الجلب؛ ليس هناك ضمان بوصول كل خبر منشور لدى الناشر.

## ملف المصادر المحلي

يبقى `sources.yml` كتالوجًا محليًا مستقلًا يدعمه المحرك، وليس قائمة اشتراكات المستخدم ولا مصدر تبويب RSS.mobi. تعديل هذا الملف لا يلغي اشتراكًا ولا يغيّر الدليل الخارجي. يُحفظ بجوار قاعدة مساحة العمل؛ لا تستبدله التحديثات.

## متابعة المقالات بدون RSS

في **إضافة رابط** اختر **تحديد تلقائي** أو **صفحة مدونة أو أخبار**، وأدخل رابط صفحة تجمع المقالات، لا رابط ترتيب النماذج. يحاول التطبيق اكتشاف RSS/Atom أولًا. إذا لم تُعلن الصفحة خلاصة، يستخرج روابط بطاقات المقالات والعناوين من HTML العام، ثم يستخدم مسار القراءة والتلخيص المعتاد.

- صفحات HTML تُفحص كل 6 ساعات على الأقل أثناء تشغيل التطبيق. يظل التحديث اليدوي متاحًا.
- أول جلب يستورد حتى 30 مقالًا ظاهرًا في الصفحة؛ هذه ليست عملية أرشفة لكل تاريخ الموقع. لا يتابع صفحات الترقيم أو أزرار «تحميل المزيد».
- يتم توحيد روابط التتبع ومنع تكرار المقالات مع الاحتفاظ بحالة القراءة والمحفوظات.
- لا يشغّل JavaScript أو متصفحًا إضافيًا أو نموذجًا لاكتشاف المقالات. لا يدخل صفحات تسجيل الدخول ولا يتجاوز الحجب. الصفحات التي لا تكشف بطاقات مقالات واضحة تعرض خطأ مع الاحتفاظ بالأخبار السابقة.
- تاريخ النشر يبقى غير معروف إن لم توفره الصفحة؛ تاريخ الاكتشاف لا يُقدَّم كتاريخ نشر.
- هذه متابعة للمقالات المنشورة وليست متابعة لدرجات البنشماركات أو تغيّر ترتيبها.

فُحص جلب Artificial Analysis (`https://artificialanalysis.ai/articles`) وArena (`https://arena.ai/blog`) باستخدام ناقل الشبكة الفعلي للتطبيق. Epoch (`https://epoch.ai/atom.xml`) وInterconnects (`https://www.interconnects.ai/feed`) يدعمان الخلاصات مباشرة. مدونة SWE-bench لم تعرض روابط مقالات قابلة للاستخراج في فحص هذه النسخة؛ لا تُعد مدعومة حاليًا.
