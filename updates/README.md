# قناة التحديث / Update channel

`tauri-preview.json` serves signed updates for the official Tauri app. The historical filename is retained for installed clients. The old `openStudio` raw URL redirects to the canonical `openNews` repository.

Promote after the archive and signature exist publicly and a real two-version upgrade passes. Private keys never belong here. See [العربية](../docs/RELEASING.md) / [English](../docs/RELEASING.en.md).

اسم القناة تاريخي للتوافق؛ الإصدار رسمي. يُنشر ملف القناة بعد اختبار التحديث وتوفر أصوله، ويشير إلى حزمة موقّعة بالمفتاح الأصلي.
